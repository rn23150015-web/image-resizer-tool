# 📦 画像リサイズアプリケーション (ECサイト向け)

## 1. アプリの概要と背景
本プロジェクトは、ECサイトにおける商品画像の登録業務などを想定した、自動画像リサイズWebアプリケーションです。
ユーザーがアップロードした画像を解析し、指定したサイズへ自動的にリサイズ処理を行います。処理後はBase64エンコードを用いたプレビュー表示を行い、手軽にダウンロードできる仕組みを構築しました。

「ただ動くものを作る」のではなく、「MVCモデルの役割分担」や「データの流れ」といった、システム開発の仕組みを深く理解するための学習として取り組みました。

## 3. 学習過程と成長のストーリー

### ① プロジェクト開始前のスキルレベル
開発開始当初は、Javaの基礎文法を終え、Servlet/JSPの学習を始めたばかりの初学者でした。エラー画面が出ると何から手をつければ良いか分からず、自信を失いやすい状態でした。

### ② 今回新たに挑戦した技術
*   **MVCの厳密な実装:** Controller（受付）、Service（処理）、Model（データ）、View（表示）の役割を明確に分離した設計。
*   **画像データの処理:** バイナリデータとBase64文字列の変換処理の実装。
*   **スコープの適切な使い分け:** 「Sessionスコープ」と「Requestスコープ」の違いを理解し、画面遷移をまたぐデータの保持と破棄を意図通りにコントロールする技術。

### ③ 開発中の課題と解決へのアプローチ
もっとも苦労したのは、Controller間でデータを受け渡す際の挙動の理解です。
この課題に対して、コードの写経で終わらせるのではなく、「データの流れを完全に可視化する」というアプローチをとりました。

## 4. 学習方法と学びの姿勢
私の学習の最大のこだわりは、「即答を求めず、自ら思考してエラーを探求すること」です。
開発中に行き詰まった際は、AIなどのツールを活用して直接的な答えを聞くのではなく、「原因を特定するためのヒント」だけを求め、自ら仮説を立ててコードを修正するプロセスを徹底しました。

また、難解な専門用語やシステムの裏側の概念（MVCの構造やサーバーの挙動など）は、自分が理解しやすい身近な概念に置き換えて構造化することで、「なぜその処理が必要なのか」を言語化して説明できるように学習を進めました。

## 5. 今後の目標と改善予定
現在、本アプリケーションのさらなる機能拡張として、PythonとAI技術（PyTorch / OpenCV）を用いた「画像の超解像（画質向上）機能」の実装に挑戦しています。

**【現在取り組んでいる課題】**
*   ローカル環境でのPython仮想環境（`venv`）の構築とパッケージ管理。
*   セキュリティ実行ポリシー制限などの環境構築エラーの自己解決。
*   学習済みAIモデルへの画像データの受け渡し処理。

最終的には、JavaのWebアプリケーションとPythonのAI処理を連携させ、より実用的で高度な画像処理システムへと昇華させていく予定です。未知のエラーにも逃げず、一つひとつ仕組みを理解しながら技術領域を広げていきます。
